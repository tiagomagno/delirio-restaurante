# Delírio Tropical — Site Estático Local

## Visão geral
Versão estática local do site delirio.com.br capturada via web scraping, base para futura migração para Node.js + Next.js.

## Stack
HTML + CSS + JS vanilla (estático).

## Estrutura
- `index.html` — Home completa
- `assets/css/style.css`, `assets/js/main.js`
- (a criar: `sobre-nos.html`, `lojas.html`, `fale-conosco.html`)

## Comandos principais
Abrir `index.html` ou rodar `python -m http.server 3000` / `npx serve .`

## Observações
Migração planejada para Next.js. Material de referência para reescrita.
